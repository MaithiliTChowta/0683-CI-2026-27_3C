**Milestone 1 CIE- Bakery sales **

Project Overview
This project focuses on analyzing a Bakery sales dataset using Python and the Pandas library. 
The dataset contains retail transaction details, including customer information, product categories, prices, quantities, payment methods, locations, and transaction dates.

Objectives Load and understand the retail sales dataset.

Explore rows, columns, data types, and statistical information.
Identify and handle missing values.
Perform data cleaning and transformation.
Analyze sales patterns and customer purchasing trends.
Generate meaningful insights from the dataset.
Create visualizations to present the findings.
